How it works

Tabular Q-learning with self-play. The board is always seen from the side of the player to move, and the 8 rotations/reflections are merged, so 4,520 positions become 627 table rows. The update is Q(s,a) ← Q + α·(target − Q). The target is +1 for a winning move, 0 for a drawing move, and otherwise −γ·max Q(s′), because the opponent's best value is minus yours.
